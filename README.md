# CMMT_based_PLIC-CLSVOF_method
This repository contain the codes (written in C++) for PLIC-CLSVOF method in Cartesian coordinate system. Finite Volume Method is used to discretize the governing equations.

# Software requirements
This solver needs:

- gcc

# How to install the required packages (on a Linux system)

To install gcc (compiler for C++ code)

```bash
sudo apt install build-essential
```

# How to compile and run the code

To compile the code

```bash
g++ driver.cpp -o output
```
To run this code

```bash
./output
```
